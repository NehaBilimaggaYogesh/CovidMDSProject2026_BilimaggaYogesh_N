# MDS Research Project Part B
## From Compliance to Choice: A Cross-National Comparison of Face Mask Behaviour Predictors in Australia and the United Kingdom

**Author: ** Neha Bilimagga Yogesh 
**Supervisor: ** Anthony Mays 
**University: ** Adelaide University
**Year: ** 2026

## Project Overview

This project extends Ryan et al. (2025) from Australia
to the United Kingdom, comparing the factors that
predicted face mask wearing behaviour before and after
government mandates using machine learning models
applied to the YouGov COVID-19 Behaviour Tracker survey.

## Files in this Repository

### R Scripts (run in this order)
1. `data_cleaning_and_models.R` - Data cleaning and
   preparation
2. `main_analysis.R` - Baseline models and mixed
   effects logistic regression
3. `stability_experiment.R` - Parameter experiment 1
4. `stability_experiment2.R` - Parameter experiment 2
5. `final_stability_analysis.R` - Final stability
   analysis
6. `generate_figures.R` - Generate all figures
